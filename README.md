# Local AI (LLMs) for Doing Ethical Research in Social Sciences — Practical Toolkit Guide (EN / 日本語)

A 100% offline, privacy-first practical handbook for running local AI models (**Ollama**, **Gemma 4 / Gemma 3**, **Qwen 2.5 Coder**, **Apple Silicon MLX Whisper `turbo`**, and **Silero Neural VAD**) with **Antigravity Guardrails**, **Dual-Agent Qualitative Pipelines**, and the **Offline Bilingual Live Teleprompter**.

## Live Documentation Site (GitHub Pages)
Once GitHub Pages is enabled (`Settings → Pages → Deploy from branch → main / /docs`), this repository serves a responsive, bilingual (**English / 日本語**) interactive documentation portal featuring:
- Instant **EN / 日本語** language switcher
- Sticky chapter & section navigation + live search
- One-click **Copy** buttons for all Terminal commands and Workshop Prompts
- Direct downloads for both Word (`.docx`) handbooks:
  - `docs/downloads/Local_LLM_Research_Toolkit_Guide_EN.docx`
  - `docs/downloads/Local_LLM_Research_Toolkit_Guide_JA.docx`
